# IT Helpdesk Database Analysis

## Project Overview
This project analyzes a sample IT Helpdesk database using SQL.
The dataset contains 6 employees and 6 helpdesk tickets.

## Key Findings

### 1. Ticket Summary
- Total tickets: 6
- Resolved tickets: 4
- Pending tickets: 2

### 2. Average Resolution Time
The average resolution time for resolved tickets is 2.5 hours.

### 3. Ticket Volume by Priority
- High: 3 tickets
- Medium: 2 tickets
- Low: 1 ticket

### 4. Department Analysis
- HR: 2 tickets
- Finance: 2 tickets

## SQL Skills Demonstrated
- SELECT and WHERE
- COUNT and AVG
- GROUP BY and ORDER BY
- CASE WHEN
- INNER JOIN and LEFT JOIN
- HAVING

## Conclusion
The analysis shows that most tickets were resolved,
with an average resolution time of 2.5 hours.
High-priority tickets represent the largest share
of the sample dataset.

Note: This project uses fictional sample data
for learning and portfolio demonstration.
